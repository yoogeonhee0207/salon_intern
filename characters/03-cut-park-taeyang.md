# 커트 디자이너 · 박태양 (가명)

| 항목 | 내용 |
|---|---|
| 역할 | 남성/단발 커트 전문. 가발 커트 사부 |
| 특기표 | 1번 남성/단발 커트 |
| 요청 확률 (%) | 잡무 25 / 샴푸 35 / 롤 0 / 염색 0 / 드라이 40 |
| 시술 속도 | ×0.7 (매우 빠름) |
| 참을성 | 낮음 |

## 성격
빠르고 직설적이고 에너지가 넘친다. 인턴을 쉴 새 없이 부르지만 악의는 없다. 손이 빨라서 남도 빨라야 한다고 생각하는 게 문제다.

## 말투
말이 짧고 빠르다. 같은 말을 두 번 하지 않는다.

## 시스템상 특징
- 회전율 담당. 손님이 빨리 돌아서 요청이 자주, 짧게 온다.
- 바닥 청소 요청이 많다(머리카락이 많이 나옴).
- 속도 배율이 ×0.7이라 샴푸 후 드라이가 금방 이어진다.

## 서사 역할
- Lv.5 가발 커트 해금 후 사부 역할
- 야간 연습의 커트 수업 이벤트(원랭스 → 단발 → 레이어드 순)

## 호감도 이벤트 아이디어
- 바쁜 날 요청을 쳐내면서 "너 손 빨라졌다" 반응
- 커트 수업에서 가이드 선을 보는 법을 알려줌

## 대표 대사 예시 (임시)
- 요청: "샴푸! 다음 손님 5분 뒤!"
- 칭찬: "오, 속도 붙었는데?"
- 수업: "잘 봐. 한 번에 간다."
