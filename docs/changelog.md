## v2.5
- 기획서 정리: 파일 이름을 game-design.md로 변경, 15장(프로토타입 확정 규칙)이 우선한다는 안내 추가
- 1~14장의 옛 내용을 15장과 맞춤(잡무 폐지, 하루 목표 건수제, 레벨별 해금과 승급시험, 시술 단계 미니게임, 요청·난이도 규칙)
- 디자이너 호칭 선생님, 롤을 펌으로 통일, 미결정 사항을 밸런스·기능·미정으로 다시 분류

## v2.4
- 승급시험을 "다음 시술을 풀기 위한 시험"으로 재배치(Lv0 샴푸, Lv1 펌, Lv2 염색, Lv3 드라이, Lv4 커트, Lv5 종합), 샴푸·펌 미니게임을 실제 작업 순서로 변경
- 시술 단계마다 짧은 직접 미니게임, 손님 만족도와 선생님 친분, 하루 보상(친분, S등급 XP)
- 하루를 목표 건수제로 변경, 빨리 감기, 아침에 같이 일할 선생님 고르기, 첫날 6종 견학
- 디자이너 호칭을 선생님으로, 롤을 펌으로 변경
- 테스트 모드(LevelConfig.TestMode): 경험치와 응시 조건 최하. 출시 전 false로 되돌릴 것

## v2.3

- 휴식은 시간 건너뛰기 방식, 시술 단계 완료 알림 추가, 레벨0 경험치 8로 하향
- 승급시험 도입: 경험치와 연습 횟수를 채우면 응시, 레벨별 전용 미니게임(순서·샴푸·롤·염색·드라이·커트·졸업)
