# 기획 변경 이력

## v2.4
- 승급시험을 "다음 시술을 풀기 위한 시험"으로 재배치(Lv0 샴푸, Lv1 펌, Lv2 염색, Lv3 드라이, Lv4 커트, Lv5 종합), 샴푸·펌 미니게임을 실제 작업 순서로 변경
- 시술 단계마다 짧은 직접 미니게임, 손님 만족도와 선생님 친분, 하루 보상(친분, S등급 XP)
- 하루를 목표 건수제로 변경, 빨리 감기, 아침에 같이 일할 선생님 고르기, 첫날 6종 견학
- 디자이너 호칭을 선생님으로, 롤을 펌으로 변경
- 테스트 모드(LevelConfig.TestMode): 경험치와 응시 조건 최하. 출시 전 false로 되돌릴 것

## v2.3
- 견학을 시술 종류당 한 번으로 하고 하는 법을 설명하는 튜토리얼 대화 추가
- 휴식은 시간 건너뛰기 방식, 시술 단계 완료 알림 추가, 레벨0 경험치 8로 하향
- 승급시험 도입: 경험치와 연습 횟수를 채우면 응시, 레벨별 전용 미니게임(순서·샴푸·롤·염색·드라이·커트·졸업)

## v2.2
- 카드 방식에서 위에서 내려다본 미용실 평면(도형 캐릭터)으로 변경, 탭으로 이동
- 하루를 현실 4분으로 조정, 예약표가 실제 요청으로 연결
- 시술별 단계 순서와 구역(샴푸실·시술석·커트석) 확정, 탈색 추가
- 잡일 카드 폐지 → 재료실 재고 시스템, 재료 부족 시 잔소리
- 바닥 청소는 커트 단계 뒤에만 발생
- 피로도와 휴식(활동 선택, 하루 휴게시간 60분, 밀리면 잔소리)

## v2.1 보완
- 엔진 확정: Unity (C#), 1인 개발
- 한 줄 콘셉트 확정: "수건 접던 막내가 가위를 잡기까지, 인턴 한 명이 매장을 돌린다" / 가제 "막내의 가위"
- 고정 인물 5명 설정 초안 추가 (characters/ 폴더): 원장 한서린, 수석 최하준, 커트 박태양, 다정 송몽실, 신입 조은새 (이름은 가명)
- 인물별 특기표 번호, 요청 확률, 서사 역할, 호감도 이벤트 아이디어, 대표 대사 예시 정리

## v2.1
- 플랫폼 확정: 모바일, 가로 화면
- 모바일 설계 원칙 추가 (요청 UI 단순화, 자동 일시정지·저장, 터치 정확도)
- 수익 모델 초안 추가: 무료 + 광고 + 인앱결제 (성장 요소는 결제로 건너뛸 수 없음)

## v2.0
