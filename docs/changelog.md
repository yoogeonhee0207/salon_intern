## v2.20
- 코드 정리(동작 변화 없음): 안 쓰던 `newArmed`·`titleNewText`·`refilledTotal` 필드, `ConsumeFor`와 `ProcedureUses`(재료 소모는 단계 기준 StepUses가 담당), `SaveData.Exists()`, `LevelConfig.ChoreRatio`를 삭제. `FindFirstObjectByType`는 `FindAnyObjectByType`으로 교체(경고 제거). 남은 경고 3개는 TestMode/AutoPassExam 상수 때문에 나오는 의도된 "도달 불가 코드" 경고
- 샴푸 미니게임 연출 보강(ShampooExam): 머리 위에 거품 방울(칸마다 2개)이 생김. 거품내기에서는 문지른 곳부터 방울이 진해지고, 물 틀기 단계에서는 거품이 가득 덮여 있고, 헹구기에서는 문지른 곳부터 사라짐. 적시기·헹구기에서 문지르면 그 자리에서 물방울이 떨어졌다 사라짐. 규칙·점수는 그대로
- 대기 보너스·지연 감점: 내가 고른 선생님 일(인턴이 대신한 일 제외)을 끝낼 때 제한시간이 60% 이상 남았으면 +5, 25% 미만이면 -5. 완료 알림에 "(빨라요 +5)" / "(오래 기다렸어요 -5)"로 표시. 상수는 GameController의 WaitFastRatio 0.6, WaitSlowRatio 0.25, WaitFastBonus 5, WaitSlowPenalty 5
- 아침 준비 화면의 상점·업적·시작 화면·처음부터 다시 버튼을 설정 창으로 이동. 아침 화면 오른쪽 위에는 "메뉴" 버튼 하나만 남고, 누르면 "메뉴" 창(소리·음량·상점·업적·시작 화면·처음부터 다시·닫기)이 뜸. 영업 중 위쪽 "설정" 버튼은 "메뉴"로 이름을 바꿨고, 일시정지 창에도 상점·업적이 들어감(시작 화면·처음부터 다시는 영업 중에는 숨김, 영업 상태가 꼬일 수 있어서). 저녁 정산 화면 오른쪽 위에도 "메뉴" 버튼 추가. 시작 화면의 설정은 그대로
- 영업 화면 아래쪽의 피로도 막대·휴식·재료실 가기 버튼 삭제(재료실·휴게실은 방을 직접 눌러 감, 피로도는 스태미너 "나" 줄). 매장 영역을 아래로 넓히고 1.05배 확대
- 가발·모델 커트는 16시부터 가능(전에는 15시). 내 커트 예약은 16:00~17:30 칸에서 뽑음. 예약 확률 감소는 그대로 15시부터
- 영업 중 예약표 다시 보기: 위쪽 바에 "예약표" 버튼(설정 왼쪽). 누르면 게임이 멈추고 오늘의 예약표가 보기 전용으로 뜸. 지금 시간 칸은 금색, 지난 칸은 흐리게, 내가 고른 선생님은 초록 ✔, 맨 아래 내 커트 줄 포함. 닫기를 누르면 이어서 진행

## v2.18
- 내 커트 줄(Lv.5 이상): 아침 예약표 맨 아래에 "★ 내 커트 (고른 선생님 기준) N건" 줄이 생겨, 내가 고른 선생님의 가발·모델 커트를 시간별로 보여줌(같은 시간에 여러 건이면 ×N). 이걸 보고 선생님을 고를 수 있음
- 같이 일할 선생님 수를 내 레벨과 같게: Lv.1 1명, Lv.2 2명 … Lv.6 6명 (Lv.0 견학 날은 1명). 전에는 1,2,3,4,5,7,8명. 그만큼 인턴이 맡는 선생님이 늘어남
- 시간대별 예약: 15시 전 칸당 0.32, 15시 이후 0.20으로 감소. 가발·모델 커트(커트 시술)는 15시 이후 예약과 일반 손님에서만 들어옴(15시 전에는 안 나옴)
- 가발·모델 커트는 인턴장(나)만 처리: 인턴이 도와주거나 대신 맡지 않음. 내가 고르지 않은 선생님의 커트 예약은 만들지 않음(인턴이 못 하는 일이라서). 내가 놓치면 기존처럼 선생님이 직접 처리한 것으로 처리
- 가발·모델 커트 손님은 특정 선생님 이름 대신 인턴장 이름으로 알림에 표시(Lv.5 이상 윤새봄 등). 자리·담당 처리는 그대로이고 표시만 바뀜. 실제 담당을 선생님과 분리하는 건 아직 안 함
- 인턴 스태미너 소모 초당 0.62 → 0.4 (100→15까지 약 212초, 일을 계속 하면 하루에 한 번 정도 쉼). 이유: 인턴이 후반에 스태미너가 바닥나 느려져 놓친 손님이 늘어남
- 인턴이 도우러 오는 시간 단축: 내가 고른 선생님 일을 8초 안에 시작하지 않으면 → 4초, 내가 못 하는 단계가 든 어려운 시술은 2초 → 1초
- 인턴 레벨 평균 +1: 내 레벨별 동료 인턴 레벨 {6,6,5} {6,6,4} {6,5,4} {6,5,4} {5,5,4} {5,4,4} {4,4,4} (내 Lv.0~6). 이유: 인턴장(Lv.6) 하루 시험 운영에서 놓친 손님 19건(내가 거의 개입하지 않은 상태, 영업 17시까지). 인턴 레벨이 오르면 작업이 빠르고(Lv.4는 1.0배, Lv.3은 1.15배) 솜씨도 올라감
