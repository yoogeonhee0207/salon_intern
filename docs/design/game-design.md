# 미용실 인턴 게임 기획서 (v2.21)

지금까지 확정된 내용을 정리한 문서입니다. 숫자는 모두 시작점이며 플레이 테스트로 조정합니다.

> **읽는 법**: 1~14장은 기본 설계, **15장은 프로토타입에서 확정한 규칙**입니다. 두 곳이 다르면 15장이 우선합니다(예: 6·7장의 인턴 구성과 직책 표는 15-1의 동료 인턴 3명 구성이 우선). 게임 안에서 디자이너는 **선생님**으로 부릅니다. 변경 이력은 [changelog](../changelog.md)를 보세요.

## 1. 게임 개요

- **장르**: 타이쿤(경영) + 미니게임 + 스토리/성장 시뮬레이션 혼합
- **핵심 구조**: 하루 단위 루프 + 인턴 성장 서사
- **톤**: 현실 기반 + 코믹한 과장
- **배경**: 번화가 프랜차이즈 미용실 (본사 점검, 지점 랭킹, 암행 손님 등 활용)
- **목표**: 막내 인턴으로 시작해 인턴 편 엔딩(졸업 평가)을 보면 디자이너 과정이 해금된다.
- **한 줄 콘셉트**: 수건 접던 막내가 가위를 잡기까지, 인턴 한 명이 매장을 돌린다
- **가제**: 막내의 가위

## 2. 하루 구조

| 시간대 | 파트 | 진행 | 내용 |
|---|---|---|---|
| 아침 | 아침 준비 | 선택형 | 오늘 예약표 확인, 같이 일할 선생님 고르기, 승급시험 응시 |
| 10:00~18:00 | 영업 | 실시간 (현실 약 4분) | 요청 처리, 미니게임, 재료실·휴게실 이용 |
| 마감 | 마감 정산 | 선택형 | 점수·등급·보상(친분, XP) 정산 |

- 영업은 **하루 목표 건수**를 받고 모두 처리하면 마감한다. 자세한 규칙은 15-10.
- 야간 연습(가발 커트 연습 등)은 아직 구현하지 않았다. 필요하면 후속으로 추가한다.

**휴식 규칙**
- 휴게실에서 활동을 골라 쉬고, 쉬는 동안 시간이 건너뛰어진다(15-6).
- 쉬는 중 손님이 너무 밀리면 선생님에게 잔소리를 듣고 감점된다.
- 피로도는 하나의 게이지로 관리한다.

## 3. 손님 시스템

- **예약 손님**: 아침에 예약표(손님, 시술, 담당 디자이너, 예상 소요시간)를 확인하고 하루를 계획한다. 일부는 "VIP (정보 비공개)"로 가린다.
- **워킹 손님**: 예약이 빈 시간에 확률적으로 등장한다. 요일, 날씨, 시간대에 따라 확률이 달라지며 코믹한 상담 이벤트의 무대가 된다.
- **충돌 변수**: 시술 지연으로 예약 손님 대기, 노쇼·지각, 시간 변경 요청.

| 상황 | 결과 |
|---|---|
| 예약 손님 제시간 응대 | 만족도 유지 |
| 워킹 손님 성공 응대 | 추가 수익, 단골 가능성 |
| 예약 손님 대기 | 만족도 하락, 클레임 위험 |
| 워킹 손님 거절 | 손해는 작지만 기회 손실 |

## 4. 레벨 구조

미해금 시술은 수행할 수 없다. 해당 요청이 오면 선생님이 직접 처리하고 인턴은 견학만 한다. 시술을 풀려면 **그 시술의 승급시험을 통과**해야 한다(15-9).

| 레벨 | 직급명(안) | 해금 요소 | 직책 |
|---|---|---|---|
| Lv.0 | 신입 인턴 | 견학(첫날 시술 6종), 재료실·휴게실 | - |
| Lv.1 | 견습 인턴 | 샴푸 | - |
| Lv.2 | 보조 인턴 | 펌 | - |
| Lv.3 | 숙련 인턴 | 염색, 탈색 | - |
| Lv.4 | 베테랑 인턴 | 드라이(블로우) | 부인턴장 |
| Lv.5 | 수석 인턴 | 가발 커트 | 인턴장 |
| Lv.6 | 졸업반 인턴 | 모델 커트 | 졸업 평가 |

- **승급 조건**: XP 가득 + 연습 횟수 충족 후 승급시험 합격(15-9).
- **Lv.0은 첫날 하루**: 모든 시술을 한 번씩 견학한다(15-10).
- 예전의 잡무 7종은 카드로 나오지 않는다. 재료실 재고 관리와 바닥 청소로 대체했다(15-4, 15-5).

## 5. 시술과 미니게임

시술은 여러 **단계**로 이루어지고(15-3), 내 레벨로 할 수 있는 단계는 짧은 미니게임으로 직접 한다(15-11). 미니게임 중에는 영업 시계와 요청 제한시간이 멈춘다.

| 단계 | 평소 미니게임 (실패 없음) | 승급시험 |
|---|---|---|
| 샴푸 | 물 틀기·적시기·샴푸·거품·헹구기 (15초, 합격 85%, 거품 방울과 물방울 연출) | 40초 안에 6단계 모두 |
| 펌 | 빗질·파지·롯드 놓기·말기·고무줄 (약 22초) | 45초 안에 5단계 모두 |
| 염색 | 4구역을 번호 순서대로 칠하기 (14초, 15-15) | 색 배합 후 도포 |
| 드라이 | 문질러 말리기 (8초) | 골고루 말리기, 과열 주의 |
| 커트 | 가이드 선 따라 가위질 (8초) | 정확도 75% 이상 |
| 탈색 | 바른 뒤 알맞은 때 헹구기 (13초, 15-15) | (염색 시험에 포함) |

- 디자이너(선생님)마다 속도 배율이 다르지만, 현재는 사용하지 않는다.
- 파마·염색·탈색 뒤의 방치 시간은 구현되어 있다(15-3의 시술 중 대기).

## 6. 인원 구성

| 구분 | 인원 | 비고 |
|---|---|---|
| 디자이너 | 10~12명 | 서사를 깊게 쓸 핵심은 3~4명 |
| 원장 | 1명 | 승급 심사, 본사 점검 대응 |
| 인턴 | 5~6명 (플레이어 포함) | 디자이너 : 인턴 = 2 : 1 이상 유지(인력난 설정) |

초기 구상은 인턴장·부인턴장·중간 인턴·동기 NPC였지만, 현재 구현은 동료 인턴 3명(인턴장, 오지후, 김나래)과 플레이어다(15-1).

## 7. 직책과 승계 서사

직책은 인턴장·부인턴장 한 명씩이다. 직책자는 인턴 휴식 배정과 업무 분배 권한을 갖는다.

| 권한 | 부인턴장 (Lv.4) | 인턴장 (Lv.5) |
|---|---|---|
| 휴식 배정 | 일부 (인턴장 승인 필요) | 최종 결정 |
| 업무 분배 | 요청 일부를 인턴에게 넘김 | 전체 요청 배분 |
| 책임 | 분배 실수 시 작은 감점 | 호감도·매장 평가에 큰 영향 |

**서사 흐름**
1. 초반(Lv.0~3): 선배 인턴의 배정을 받으며 일을 배운다.
2. 1차 전환점(Lv.4): 인턴장 졸업, 플레이어가 부인턴장을 승계한다.
3. 2차 전환점(Lv.5): 인턴장도 졸업, 플레이어가 인턴장이 된다.
4. 후반(Lv.5~6): 새 막내가 입사하고, 플레이어가 가르치며 졸업 평가를 준비한다.

선배 졸업 시점은 플레이어 레벨에 연동하거나 이벤트로 고정하고 레벨업 속도를 맞춘다.

## 8. 요청 시스템 (확률 기반)

1. 아침 예약표가 있다면 그 시간에 해당 선생님의 요청이 카드가 된다(고른 선생님만).
2. 예약이 목표 건수보다 적으면 부족한 만큼 고른 선생님의 일반(워킹) 요청으로 채운다.
3. 시술 종류는 선생님별 확률표(9장)로 뽑는다. 미해금 시술이 뽑히면 잠금 요청이 되며 견학만 가능하다.

| 레벨 | 잠금 요청 노출 |
|---|---|
| Lv.0 | 15% (첫날은 6종 전부 견학) |
| Lv.1 | 15% |
| Lv.2 | 12% |
| Lv.3 | 10% |
| Lv.4 이상 | 0% |

- 잡무는 더 이상 요청으로 나오지 않는다(재료실로 대체).
- 견학은 시술 종류마다 한 번만 한다.
- **후속 보정 후보**: 호감도, 시간대(오전/점심/저녁), 선생님의 바쁨.

## 10. 난이도 규칙

| 항목 | 결정 요인 |
|---|---|
| 하루 목표 건수 | 레벨 (Lv.0 3건 → Lv.6 10건) |
| 동시 요청 수 | 레벨 (Lv.0~1 2건 → Lv.4 이상 5건) |
| 요청 제한시간 | 선생님 참을성 + 레벨 + 시술 단계 수 + 친분 + 피로도 |
| 피로도 쌓이는 속도 | 레벨이 낮을수록 빠름(15-10) |

- 제한시간을 넘긴 요청은 선생님이 직접 처리하며 점수와 친분이 떨어진다.
- 난이도가 오를수록 편의 요소(선반 확장, 단골 선생님의 도움)를 함께 해금한다.

## 11. 커트와 졸업

- **Lv.5 가발 커트**: 실패 부담이 없는 연습용. 야간 연습과 승급 과제가 주 무대이며 원랭스, 단발, 레이어드 순으로 기법을 해금한다.
- **Lv.6 모델 커트**: 되돌릴 수 없는 정밀 조작. 원장과 수석 디자이너가 지켜보는 졸업 평가이며, 통과하면 디자이너 과정이 해금된다.

## 12. 랜덤 인턴 생성 시스템

새 게임 시작 시 인턴을 한 번 뽑고, 그 판 동안 고정한다. 인턴 1명당 성격 1 + 업무 스타일 1 + 버릇 1을 뽑으며 각 항목은 시스템 수치에 영향을 준다.

**성격 (10종)**: 열정 과다(빠르지만 실수 많음), 느긋함(안정적·느림), 눈치 빠름(호감도 상승 빠름), 소심함(지적에 위축·칭찬에 크게 상승), 허세(어려운 일 자원·성공률 변동 큼), 깐깐함(품질 높음·느림), 긍정왕(실패해도 컨디션 하락 적음), 수다쟁이(만족도 보너스·시간 지연), 승부욕(라이벌과 비교 시 성능 상승), 무뚝뚝(응대 점수 낮음·품질 안정)

**업무 스타일 (10종)**: 샴푸 달인, 염색 달인, 손이 빠름(시계 ×0.85·품질 약간 감소), 꼼꼼함(시계 ×1.15·품질 보너스), 잡무 장인, 만능형, 드라이 감각, 펌 장인, 응대 천재, 멀티태스커(방치 시간 활용 효율 상승)

**버릇/약점 (10종)**: 땡땡이, 먹는 데 진심, 쉽게 지침, 지각, 선생님 눈치 과다, 전화 공포증, 손 떨림(긴장 구간 품질 하락), 방향감각 부족(도구 위치 혼동), 졸음(오후 속도 하락), 연애 고민(랜덤 이벤트로 집중 못 하는 날)

**밸런스**: 각 항목에 -2~+2 점수를 매기고 한 인턴의 합이 +1~+2가 되도록 뽑는다. 범위를 벗어나면 다시 뽑는다.

**제외 조합**: 손이 빠름+느긋함, 꼼꼼함+열정 과다, 잡무 장인+지각, 깐깐함+졸음, 소심함+허세, 응대 천재+무뚝뚝, 손 떨림+승부욕

**역할별 적용**

| 인턴 | 랜덤 범위 |
|---|---|
| 인턴장 NPC | 엄격한 선배 톤 고정, 성격은 깐깐함·눈치 빠름·느긋함 중에서 뽑기 |
| 부인턴장 NPC | 다정한 선배 톤 고정, 허세·소심함 제외 |
| 중간 인턴, 동기, 새 막내 | 3개 축 모두 완전 랜덤 |

**대사 템플릿**: 성격 10종 기준으로 제작(첫 소개, 휴식·업무 배정 반응, 졸업 이벤트, 새 막내 입사). 1차로 열정 과다·소심함·느긋함·허세 4종을 만들고 나머지는 2차에 추가하며, 대사가 없는 성격은 기본 대사를 쓴다.

**이름·별명**: 성 12종 + 이름 40종 풀에서 조합하고, 성격에 맞는 별명 풀을 따로 둔다(예: 수다쟁이 → 스피커).

외형은 처음에는 고정 몇 벌 중 선택하고 파츠 랜덤은 후속으로 미룬다.

## 13. 플랫폼과 모바일 설계 원칙

- **플랫폼**: 모바일 (Android/iOS), **가로 화면 고정**
- **엔진**: Unity (C#), 1인 개발

**모바일 설계 원칙**
1. **요청 UI 단순화**: 요청 카드는 아이콘 중심의 한 줄 구성(디자이너 얼굴, 시술 아이콘, 남은 제한시간 바)으로 하고, 동시 요청이 5건 이상이어도 한 화면에 들어가게 한다. 예약표는 버튼을 눌러 여는 방식으로 두고, 영업 중에는 다음 예약 1~2건만 상단에 요약한다.
2. **중단과 이어하기**: 전화, 알림, 앱 전환 시 영업 중 자동 일시정지. 하루 시작·마감 시점과 파트 전환마다 자동 저장하며, 영업 도중 종료하면 복귀 시 일시정지 상태로 이어서 한다.
3. **터치 정확도**: 드래그형 미니게임은 판정을 너그럽게 잡는다. 염색 도포와 모델 커트 같은 정밀 조작은 확대 보조와 가이드 선을 제공한다. 손가락에 가려지지 않게 조작 영역과 결과 표시 영역을 분리한다.
4. **세션 길이**: 하루 한 판은 현실 약 10~15분 이내(선택형 파트 포함)를 목표로 한다.

## 14. 수익 모델 (무료 + 광고 + 인앱결제)

기본은 무료 게임이며 광고와 인앱결제로 수익을 낸다. 아래는 초안 원칙이며 출시 전에 다시 검토한다.

**원칙**
- 레벨업, 시술 해금, 졸업 평가 통과는 **결제로 건너뛸 수 없다.** 성장 서사가 이 게임의 핵심이기 때문이다.
- 영업 중 강제 광고는 넣지 않는다. 광고는 **플레이어가 선택하는 보상형 광고**를 중심으로 한다.

**보상형 광고 후보**
- 컨디션(피로도) 회복, 아침 버프 추가, 정산 시 팁·XP 보너스 2배, 야간 연습 추가 기회, 실패한 하루 한 번 재도전

**광고 위치**: 하루 종료 후 정산 화면, 파트 전환 구간처럼 흐름이 끊겨도 되는 곳에만 둔다.

**인앱결제 후보**
- 광고 제거 패키지
- 외형 아이템: 인턴 유니폼, 헤어 스타일, 미용실 인테리어 (성능에 영향 없음)
- 편의 아이템: 정리 선반 추가 등 (난이도를 낮추는 정도가 지나치지 않게 조정)
- 후속 콘텐츠: 디자이너 편 해금 방식은 별도 결정 필요(결제로 해금하면 인턴 편 엔딩 보상과 충돌)

**주의점**
- 광고 시청이 필수가 되는 구조(피로도가 너무 빨리 쌓임 등)는 피한다.
- 시간 제한 요청이 핵심인 게임이라 유료 시간 정지·연장 아이템은 밸런스를 크게 깨므로 제외하거나 엄격히 제한한다.

## 15. 프로토타입에서 확정한 플레이 규칙

프로토타입을 만들며 정한 규칙입니다. 앞 장과 다르면 이 장이 우선합니다. 숫자는 모두 임시값입니다.

### 15-1. 화면과 조작
- 카드 방식을 버리고 **위에서 내려다본 미용실 평면**으로 변경. 모든 인물은 도형 캐릭터(그림은 나중에 교체)
- 왼쪽 위에 스태미너 표시(나, 인턴장, 오지후). 내 값은 100 - 피로도, 인턴 값은 실제로 작업 속도에 영향(일하면 초당 0.4 줄고 휴게 중 초당 약 3.3 참)
- 같이 일하는 인턴 NPC는 3명: 인턴장(직책으로 부름), 오지후, 김나래(이름으로 부름). Lv.5부터는 내가 인턴장이 되고 선배 인턴장 자리에 새 막내(윤새봄)가 들어옴. 인턴도 스태미너가 있어 낮을수록 느려지고(최대 2.2배) 15 이하면 스스로 쉬러 감(휴식 최대 게임 1시간). Lv.5~ 스태미너 표시 옆 "휴식" 버튼으로 인턴을 쉬러 보냄(스태미너 50 이하일 때만). 한가한 인턴은 내 선생님 일을 4초 뒤 도와줌. 디자이너(선생님)는 10명(위 5, 아래 5). 작업 중 이름표는 작업 이름과 남은 시간만 표시(앞의 6·12장의 "중간 인턴", "동기" 호칭은 옛 표현)
- 플레이어는 인턴 한 명("나")을 탭으로 이동. 다른 인턴(NPC)은 후속 작업
- 디자이너 자리 10개(위 5, 아래 5), 가운데 복도, 왼쪽에 휴게실·재료실, 오른쪽에 샴푸실·시술석. Lv.5부터 오른쪽 끝 위·아래에 커트석 2개
- 위쪽 바에는 "예약표"(영업 중 예약표 보기)와 "메뉴"만 있다. 예전 하단의 피로도 막대·휴식·재료실 가기 버튼은 없앴고, 휴게실·재료실은 방을 직접 눌러 가며 피로도는 스태미너 표시의 "나" 줄에서 본다. 매장 화면은 하단 막대 자리까지 넓히고 1.05배 확대했다
- 디자이너가 요청하면 그 머리 위에 말풍선(요청 내용 + 남은 시간 막대). 예약 손님은 연한 파란색, VIP는 노란색, 아직 못 하는 시술은 회색(견학 XP +1)
- 말풍선을 누르면 디자이너 자리로 가서 손님을 모시고 단계별 구역으로 이동

### 15-2. 하루 시간
- 영업 시간 10:00~18:00을 현실 4분(240초)으로 진행. 게임 시계는 현실 1초에 2분
- 요청 제한시간, 이동 속도, 미니게임 시간은 현실 초 기준
- 아침 예약표(가로 시간, 세로 디자이너, 칸에 시술 이름)가 영업 중 해당 시간에 실제 요청이 됨. 예약 완료 +10점, VIP +30점

### 15-3. 시술 진행 순서
| 시술 | 순서 |
|---|---|
| 샴푸 | 샴푸 |
| 드라이 | 샴푸 → 드라이 |
| 커트 | 샴푸 → 커트 → 드라이 |
| 파마 | 샴푸 → 커트 → 펌 → 샴푸 → 드라이 |
| 염색 | 염색 → 샴푸 → 드라이 |
| 탈색 | 탈색 → 샴푸 → 염색 → 샴푸 → 드라이 |

- 구역: 샴푸는 샴푸실, 펌·염색·탈색은 시술석, 커트와 드라이는 선생님 자리
- 샴푸실에는 **샴푸대 2대**가 있고 손님이 누워서 머리를 감음(인턴은 머리 쪽 뒤에 섬). 시술석은 넓은 테이블에 **의자 5개**가 줄지어 있고 손님이 앉으면 인턴이 뒤에서 시술함. 단계가 끝나면 샴푸대·의자를 비움
- 시술 중 대기: 펌(롯드 말기 뒤 20분), 염색(약 작용 15분), 탈색(20분) 단계가 끝나면 손님이 시술석 의자에 앉아 기다림(게임 속 분). 그동안 인턴은 다른 요청을 할 수 있고, 의자는 계속 차 있음. 대기 중에는 요청 제한시간이 멈추고, 인턴이 할 일이 없으면 빨리 감기. 대기가 끝나면 카드가 초록색으로 바뀌며, 카드를 눌러 손님을 모시러 가서 다음 단계(샴푸 등)로 진행
- 대기 시간 보상과 벌점: 대기 중에 다른 일을 하나 끝낼 때마다 +6점(최대 3건). 대기가 끝난 뒤 게임 시간으로 10분(약 5초)이 지나면 카드가 주황색이 되고 "약 과해요 +N분"이 뜨며, 모시러 갈 때 초과 1분당 만족도가 4%씩 깎임(최저 20%)
- 시술석 의자 5개는 모든 레벨에서 같고, 의자 하나에 손님 한 명만 앉음. 의자가 모두 차 있으면 새로 시작할 수 없고 다른 요청을 먼저 해야 함. 시술 중간에 의자가 필요한데 자리가 없으면 손님이 의자가 비기를 기다림
- 쉬운 단계 맡기기: 내 레벨이 그 단계를 연 레벨보다 2 이상 높으면(샴푸 Lv.3~, 펌 Lv.4~, 염색·탈색 Lv.5~, 드라이 Lv.6~, 커트 제외) 한가한 인턴(그 단계를 할 수 있는 가장 높은 레벨)이 대신 함. 끝나면 카드가 초록색이 되어 내가 모시러 가서 이어받음. 인턴이 바쁘면 내가 직접 함. 한 단계짜리 시술은 맡기지 않음. 인턴의 솜씨가 만족도에 들어감
- 인턴이 일을 고를 때는 내가 못 하는 단계가 많이 든 어려운 시술부터, 같으면 점수가 높은 시술부터 맡음. 내 선생님 일을 도울 때도 같은 순서이고, 못 하는 단계가 든 시술은 2초 뒤부터 도움
- 내가 못 하는 단계는 그 단계를 할 수 있는 인턴(나보다 높은 레벨)이 대신 해줌. 해줄 인턴이 없어서 선생님이 하는 경우도 감점 없음(내가 못 하는 단계이므로)
- 내가 할 수 있는 단계도 미니게임 화면의 "선생님께 맡기기"로 넘길 수 있음(4초, 완성도 70%). 하루 한도 레벨별 5/4/3/3/2/2/1회, 초과 1회당 -10점(견학 날 제외)
- 난이도: 예약 확률 15시 전 0.32 / 15시 이후 0.20, 요청 제한시간 38/33/28/23/18/18/18초. 가발·모델 커트(Lv.5~, 16시부터)는 선생님 예약이 아니라 커트석 2개(선생님 자리 오른쪽 끝 위/아래, 공석)에서 하는 별도 예약이고, 인턴장(나)만 할 수 있음. 하루 3~4건을 16시 이후 칸에서 뽑아 아침 예약표 맨 아래 "내 커트" 줄에 선생님 선택과 무관하게 표시. 커트석 손님은 친분 없음
- 영업 중에도 위쪽 바 "예약표" 버튼으로 오늘의 예약표를 보기 전용으로 다시 볼 수 있음(게임 일시정지, 지금 시간 칸 강조, 지난 칸 흐림)
- 아침에 고르는 선생님 수 = 내 레벨(Lv.1 1명 … Lv.6 6명, 견학 날 1명). 인턴 레벨은 내 레벨별로 {6,6,5} … {4,4,4}(Lv.6), 인턴 스태미너 소모 초당 0.4, 도우러 오는 시간 4초(어려운 시술 1초)
- 단계마다 인턴이 직접 할 수 있는 레벨이 있음: 샴푸 1, 펌 2, 염색·탈색 3, 드라이 4, 커트 5. 직접 할 수 있으면 약 1.5초, 못 하면 디자이너가 하는 동안 약 4초 기다림
- 시술 자체가 아직 못 하는 것이면 잠금 요청(견학만 가능). 탈색은 임시로 Lv.3 해금, 커트(가발 Lv.5, 모델 Lv.6)와 탈색은 모든 디자이너 공통 확률(약 20%, 약 12%)
- 점수는 10 + 5 × 단계 수. 요청 제한시간은 단계가 하나 늘 때마다 50%씩 길어짐
- 대기 보너스·지연 감점: 내가 고른 선생님 일(휴게 중인 인턴 대신 한 일 제외)을 끝낼 때 제한시간이 60% 이상 남았으면 +5, 25% 미만이면 -5. 완료 알림에 "(빨라요 +5)" / "(오래 기다렸어요 -5)"로 표시

- 이동: 내 이동 속도는 고정(600). 손님도 같은 속도로 걸어서 따라오고 자리에 앉거나 누움(순간이동 없음). 인턴(동료) 속도는 380

### 15-4. 바닥 청소
- 잡일(수건 접기 등)은 더 이상 카드로 나오지 않음
- 바닥 청소는 **커트 단계가 끝난 뒤** 그 선생님 자리 앞에 나타나는 요청(제한 45초, 머리카락 쓸기 미니게임)

### 15-5. 재료실
- 재료: 수건 30, 도구 20, 음료 20, 청소용품 5. 매일 가득 채워서 시작
- 시간이 지나면 조금씩 줄고, 시술 단계마다 쓰임(샴푸=수건, 펌=도구+음료, 염색·탈색·커트=도구, 드라이=수건+청소용품)
- 재료가 0이거나 필요한데 없으면 선생님에게 혼남(점수 -10, 같은 재료는 20초에 한 번)
- 재료실에서 하나를 고르면 한 번에 전부 채움(게임 시계 4분). 도중에 나가면 찬 만큼만 남음. 다 채울 때마다 XP +1
- 응대 보조, 전화·예약 메모 같은 잡일은 재고로 만들기 어려워 보류

### 15-6. 피로도와 휴식
- 시술 단계를 마치면 피로도가 쌓이고, 높을수록 새 요청의 제한시간이 최대 30% 줄어듦
- 하루 휴게시간은 총 60분(게임 시계). 일찍 나오면 남은 시간만큼 다시 쉴 수 있음
- 휴게실에서 활동을 고름(고르는 동안 시계 정지): 밥 먹기 30분 -30(12~14시 -45), 낮잠 40분 -50(잔소리 기준 1 낮아짐), 핸드폰 15분 -10, 스트레칭 10분 -10
- 쉬는 중 손님이 밀리면(동시 요청 최대치 - 1, 최소 2장) 잔소리를 듣고 점수 -20, 휴식 종료
- 손님을 데리고 가던 중 휴게실·재료실로 가면 손님은 자리로 돌아가고 그 요청은 처음부터 다시

### 15-7. 견학과 알림
- 견학은 시술 종류마다 한 번만 진행하며, 시술 순서와 하는 법을 설명하는 대화가 나옴(XP +2)
- 휴식은 시간을 건너뛰는 방식(게임 시계가 활동 시간만큼 즉시 진행)
- 시술 단계 완료, 놓침, 잔소리 같은 중요한 일은 화면 위쪽 알림(토스트)으로 알림
- Lv.0은 승급 XP를 8로 낮춰 견학만으로 승급 조건을 채울 수 있게 함

### 15-8. 승급시험 규칙 요약
- 시험은 하루에 한 번만 응시, 응시 조건은 15-9 참고
- 시험 중에는 영업 시계가 멈춤. 실패하면 다음 날 다시 도전

### 15-9. 승급시험
- 다음 레벨에서 풀리는 시술의 시험을 먼저 통과해야 그 시술을 할 수 있음. 응시 조건은 경험치 가득 + 연습 횟수(Lv0은 견학 6종), 하루 한 번만 응시
- 레벨별 시험(시술 순서에 맞춘 전용 미니게임):
  - Lv0 → 샴푸: 수도꼭지로 물 틀기 → 적시기 → 샴푸통으로 샴푸 짜기 → 거품내기 → 물 틀기 → 헹구기
  - Lv1 → 펌: 휘어진 머리 빗기 → 파지 올리기 → 롯드 놓기 → 롯드 말기 → 고무줄 놓기
  - Lv2 → 염색(탈색 포함): 색 배합(한 칸 차이 허용) 후 뿌리부터 도포(80% 이상)
  - Lv3 → 드라이: 골고루 말리기, 한곳에 오래 두면 과열(2번까지)
  - Lv4 → 커트: 가이드 선 따라 드래그, 정확도 75% 이상
  - Lv5 → 종합: 파마·염색·탈색 순서 맞추기
  - Lv6 졸업시험: 탈색 순서 → 커트 → 타이밍(6번 중 5번, 라운드마다 빨라지고 구간이 좁아지며 가운데를 맞추면 "완벽!"), 하나라도 실패하면 불합격
- 시간 제한, 합격 기준 수치는 임시값이며 테스트하며 조정

### 15-10. 하루 구성
- 첫날(Day 1, Lv0)은 모든 시술 6종을 한 번씩 견학하는 날. 예약 손님 없음
- 둘째 날부터 레벨별 하루 시술 목표 건수(Lv0 3, Lv1 4, Lv2 5, Lv3 6, Lv4 7, Lv5 8, Lv6 10)를 받으면 새 요청이 끊기고, 남은 요청이 끝나면 마감
- 처리할 요청도 하는 일도 없으면 시간이 4배속으로 흐름(빨리 감기)
- 오늘 같이 일할 선생님을 아침 예약표에서 내 레벨 수만큼 고름(Lv.1 1명 … Lv.6 6명, 견학 날 1명). 예약표에서 시술 종류를 보고 고르며, 고른 선생님의 손님만 옴
- 호칭: 디자이너는 선생님으로 부름
- 피로도는 레벨이 낮을수록 빨리 쌓임(배율 Lv0 1.5 ~ Lv6 0.6)

### 15-11. 시술 단계 미니게임과 만족도
- 내 레벨로 할 수 있는 단계는 직접 짧은 미니게임(8~22초, 실패 없음)으로 진행하고, 완성도(0~100)로 S/A/B/C 등급을 받음. 승급시험의 가벼운 버전
- 단계 완성도의 평균이 손님 만족도: 점수는 만족도에 따라 0.7~1.3배
- 선생님 친분(0~100): 만족도 S +4, A +2, B 0, C -2, 놓침 -3. 높으면 제한시간 최대 +20%, 점수 보너스 최대 +10. 예약표 이름 옆 ♥로 표시
- 하루 보상: 같이 일한 선생님 친분 S +6 / A +3 / B +1, S등급이면 XP +2
- XP는 만족도로 정해짐: 시술 S +3 / A +2 / B +1 / C 0 (단순 요청 S +2 / A +1 / B +1 / C 0). XP는 줄지 않음
- 인턴(동료)도 재료를 쓰고 재료실에서 채움
- 미니게임 표현: 샴푸·드라이는 두상 전체를 붓처럼 문질러 칠함(드라이는 젖은 머리 → 마른 머리). 염색(4구역 순서)과 탈색(기다렸다 헹구기)은 15-15처럼 방식이 따로 있음. 펌·커트는 점선 따라 그리기, 펌 빗질은 꼬불한 머리를 1자로 폄. 샴푸는 15초 / 합격 85%
- 하루 목표 점수 = 하루 목표 건수 x 30점 (S는 1.2배 이상, A는 목표 이상, B는 60% 이상)

### 15-12. 손님 성격과 암행 손님
- 시술 손님에게 이름과 성격이 있음: 일반 45% / 까다로운 15% / 수다쟁이 12% / 아이 8% / 급한 10% / 단골 10%. 손님을 모시고 출발할 때 인사 대사, 시술이 끝나면 만족도에 따른 반응 대사가 나옴
- 까다로운 손님: 제한시간 x0.85, 만족도 S면 +12점, 60 미만이면 -8점
- 수다쟁이 손님: 제한시간 x1.15, 항상 팁 +3점
- 아이 손님: 만족도 60 이상이면 담당 선생님 친분 +1
- 급한 손님: 제한시간 x0.7, 만족도 60 이상 +6점 / 미만 -4점. 단골 손님: 만족도 60 이상이면 +3점과 선생님 친분 +2.
- 암행 손님은 Day 3부터 하루 최대 1명, 약 15% 확률로 일반 손님인 척 옴. 미리 알려주지 않음
  - 본사 점검: 시술이 끝났을 때 만족도 60 이상이면 +40점, 아니면 -20점
  - 리뷰 블로거(Day 5부터, 암행의 40%): 만족도 85 이상이면 +30점·포인트 +20, 60 미만이면 -15점
- 인사 대사는 성격마다 5개, 반응 대사는 일반 5개씩에 성격 전용 반응이 절반 확률로 섞임

### 15-13. 선생님 친분 이벤트와 원장·졸업 연출
- 친분 25 / 50 / 80을 처음 넘은 다음 날 아침에 대화 이벤트: 비법(포인트 +20), 간식(휴게실 간식 +1), 추천서(포인트 +100과 3일간 피로도 x0.8). 선생님마다 단계별로 한 번씩, 하루에 선생님당 한 단계씩만
- 하루 마감 정산 화면에 등급별 원장님 한마디(등급마다 5개)
- 졸업 연출(5쪽, 첫 쪽에 시험 성공 횟수와 "완벽" 횟수 표시): 합격 → 원장님 인정 → 가장 친한 선생님 축하 → 새 막내 입사 → 인턴 편 끝

### 15-14. 포인트, 상점, 업적, 목표, 주간 평가
- 포인트(예전 골드): 하루 평가 보상 S 30 / A 20 / B 10 / C 3, 업적·오늘의 목표·주간 평가·친분 이벤트로도 얻음
- 상점(아침 화면의 "메뉴" 버튼 안, 업적·시작 화면·처음부터 다시도 같은 메뉴에 있음): 도구 모양 6종(샤워 호스, 거품, 빗, 드라이기, 가위, 염색 붓) + 유니폼(내 캐릭터 색) + 인테리어(바닥·복도 색)을 각 4가지 중 고름(0 / 60 / 120 / 300P). 휴게실 간식은 40P, 다음 휴식 회복 x1.3
- 매장 업그레이드(상점 위쪽 버튼): 재료실 확장 / 휴게실 소파 / 편한 신발, 각 3단계, 단계별 60 / 120 / 240P. 재료 최대치 +10(청소용품 +2), 휴식 회복 +10%, 피로 증가 -5%씩
- 업적 12개(첫 출근, 첫 시술, S등급 달인 등), 달성하면 10~200P. "메뉴" 안의 "업적"에서 확인
- 오늘의 목표(둘째 날부터 하루 1개): 만족도 A 이상 N건 / 요청을 놓치지 않기 / 재료가 떨어져서 혼나지 않기. 달성하면 +15P
- 주간 평가: 7일마다 그 주 점수 합계로 본사 평가 등급, 포인트 S 100 / A 60 / B 30 / C 10. 추가로 한 주 놓친 손님 0명이면 +30, S등급 2일 이상이면 일수 x10(최대 30)

### 15-15. 염색·탈색 미니게임(영업 중)
- 염색: 머리를 십자 4구역으로 나눠 1→2→3→4번(왼쪽 위부터 시계 방향) 순서로 한 구역씩 칠함. 구역 진행도 80%면 다음 구역. 순서가 아닌 구역은 칠해지지 않고 실수당 완성도 -3. 제한시간 14초
- 탈색: 먼저 탈색제를 머리 80% 바르면 기다리는 단계. 6초 동안 머리색이 갈색→주황→노랑→옅은 노랑→상한 회색으로 변하고, 초록 구간(65~80%)에서 "헹구기!"를 눌러야 함. 완성도 = 바르기 40% + 타이밍 60%. 끝까지 두면 타이밍 0점. 제한시간 13초
- 졸업 시험의 마지막 타이밍 바: 라운드마다 속도 x1.08, 구간 x0.94, 가운데 30%를 맞추면 "완벽!"

### 15-16. 저장과 시작 화면
- 메뉴 창(아침 화면 오른쪽 위 "메뉴", 저녁 정산 화면 "메뉴", 영업 중 위쪽 바 "메뉴"): 소리 켜기/끄기, 음량, 상점, 업적, 닫기. 아침·저녁에는 시작 화면, 처음부터 다시(두 번 눌러야 함)도 있음. 영업 중에 열면 "일시정지" 창이 되어 시간이 멈추고, 상점·업적, 계속하기, 오늘 영업 마치기(두 번 눌러야 함)가 있음(영업 상태가 꼬일 수 있어 시작 화면·처음부터 다시는 뺌). 시작 화면에서도 "메뉴"로 소리 설정 가능
- 아침이 시작될 때와 승급시험이 끝날 때 자동 저장(PlayerPrefs), 오른쪽 위에 "저장 중..." 표시
- 시작 화면: 저장 칸 3개(칸마다 이름·Day·레벨 표시, 빈 칸은 새로 시작, 칸별 삭제는 두 번 눌러야 함). 포인트·업적·상점 구매는 칸마다 따로 저장됨. 새 시작이면 입사 서류(이름, 성별, 미용실 이름)를 씀
- 미니게임에서는 마우스 커서가 도구 모양(샤워 호스, 거품, 빗 등)으로 바뀜
- 소리: 소리 파일 없이 코드로 만든 효과음(버튼, 성공·실패 알림, 마감 팡파르, 업적, 물·가위질)과 배경음. 시작 화면·아침 화면·영업 중 오른쪽 위의 "메뉴" 버튼에서 켜고 끄고 음량(10% 단위)을 조절하며 저장됨. 나중에 제대로 된 음원으로 교체할 자리

### 15-17. 그림(아트)
- 캐릭터·가구·버튼·말풍선 그림은 `tools/make_art.py`로 코드로 그려서 `Assets/Resources/Art`에 저장(임시 그림). 나중에 제대로 된 그림으로 같은 이름의 PNG를 덮어쓰면 바로 교체됨
- 파일 이름: `designer_0~11`(선생님), `intern`+`intern_uniform`(인턴 몸+유니폼 색 입히는 층), `customer_0~3`(손님 성격별: 평범, 까다로운, 수다쟁이, 아이. 급한 손님은 까다로운, 단골은 수다쟁이 그림을 같이 씀), `floor_tile`, `corridor_tile`, `room_rest`, `room_supply`, `zone_wash`, `zone_seat`, `seat_chair`, `ui_button`, `ui_bubble`, `ui_panel`
- 그림이 없으면 예전 도형으로 대신 보여줌. 아직 도형인 곳: 미니게임 화면, 시작 화면 가위, 날씨 같은 장식

### 15-18. 개발용 설정
- `LevelConfig.AutoPassExam`(지금은 false)이 켜져 있으면 승급시험 미니게임을 건너뛰고 자동 합격. **출시 전에 반드시 끄기**
- `LevelConfig.TestMode`(지금은 false)가 켜져 있으면 하루 끝·Lv± 버튼이 상단에 보이고 승급 XP와 시험 응시 조건(견학·연습 횟수)이 모두 1로 줄어듦. **출시 전에 반드시 끄기**
- `GameController.Extras.cs`의 `ExtrasTest`를 켜면 암행 손님 100%, 이벤트 기준 1/2/3, 주간 평가 매일, 시작 때 포인트 +300과 친분 +3, 졸업 연출 미리보기가 나옴. 평소엔 false
- 승급시험 원래 조건: XP는 Lv.0 8, 이후 10 + 5 x 레벨. 연습 횟수는 견학 6종, 샴푸 6회, 펌 4회, 염색 4회, 드라이 5회, 커트 3회, 졸업은 시술 총 20회

### 15-19. 선생님·인턴 성격 (v2.22)
- 선생님 성격 4종(designers.json의 trait): 급함(제한시간 절반 이상 남기고 끝내면 +3), 느긋함(오래 기다려도 감점 없음), 완벽주의(S +4 / B 이하 -4), 다정함(A 이상 +2점, 친분 추가 +1). 예약표 이름 옆에 [급][느][완][다]로 표시, 첫 완료 때 한 줄 소개
- 인턴 성격 10종: 깐깐함, 눈치 빠름, 느긋함, 덜렁이, 성실함, 수다쟁이, 겁쟁이, 승부욕, 낙천적, 소심함. 작업 속도·솜씨·스태미너 감소·휴게 회복에 작은 배율이 붙음. 인턴장은 깐깐함·눈치 빠름·느긋함 중에서만. 새 게임마다 한 번 정해져 저장됨. 상황별 대사 5종(영업 시작, 휴게, 도움, 완료, 지침)

## 16. 미결정 사항
