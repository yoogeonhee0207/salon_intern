# 미용실 인턴 게임 기획서 초안 (v2.2)

지금까지 확정된 내용을 정리한 문서입니다. 숫자는 모두 시작점이며 플레이 테스트로 조정합니다.

## 1. 게임 개요

- **장르**: 타이쿤(경영) + 미니게임 + 스토리/성장 시뮬레이션 혼합
- **핵심 구조**: 하루 단위 루프 + 인턴 성장 서사
- **톤**: 현실 기반 + 코믹한 과장
- **배경**: 번화가 프랜차이즈 미용실 (본사 점검, 지점 랭킹, 암행 손님 등 활용)
- **목표**: 막내 인턴으로 시작해 인턴 편 엔딩(졸업 평가)을 보면 디자이너 과정이 해금된다.
- **한 줄 콘셉트**: 수건 접던 막내가 가위를 잡기까지, 인턴 한 명이 매장을 돌린다
- **가제**: 막내의 가위

## 2. 하루 구조

| 시간대 | 파트 | 진행 | 내용 |
|---|---|---|---|
| 09:00~10:00 | 아침 준비 | 선택형 | 청소, 세팅, 조회, 오늘의 예약표 확인 |
| 10:00~18:00 | 영업 | 실시간 (현실 8~10분) | 요청 처리, 미니게임, 워킹 손님 대응 |
| 18:00~19:30 | 저녁 마감 | 선택형 | 마감 청소, 정산(만족도·팁·XP) |
| 19:30~21:00 | 야간 연습 | 선택형 | 가발 커트 연습, 코칭. 피로도가 다음 날에 영향 |

**휴식 규칙**
- 식사·휴식 시간은 고정하지 않고, 손님이 없는 틈을 플레이어가 판단해 쉰다.
- 식사 중 손님이 오면 복귀 여부를 선택한다. 복귀하면 식사를 못 하고, 안 하면 선배에게 지적받는다.
- 피로도와 배고픔은 하나의 컨디션 게이지로 통합한다.
- 쉴 틈이 너무 없을 때를 대비해 강제 휴식이나 한가한 구간을 배치한다.

## 3. 손님 시스템

- **예약 손님**: 아침에 예약표(손님, 시술, 담당 디자이너, 예상 소요시간)를 확인하고 하루를 계획한다. 일부는 "VIP (정보 비공개)"로 가린다.
- **워킹 손님**: 예약이 빈 시간에 확률적으로 등장한다. 요일, 날씨, 시간대에 따라 확률이 달라지며 코믹한 상담 이벤트의 무대가 된다.
- **충돌 변수**: 시술 지연으로 예약 손님 대기, 노쇼·지각, 시간 변경 요청.

| 상황 | 결과 |
|---|---|
| 예약 손님 제시간 응대 | 만족도 유지 |
| 워킹 손님 성공 응대 | 추가 수익, 단골 가능성 |
| 예약 손님 대기 | 만족도 하락, 클레임 위험 |
| 워킹 손님 거절 | 손해는 작지만 기회 손실 |

## 4. 레벨 구조

미해금 시술은 수행할 수 없다. 해당 요청이 오면 디자이너가 직접 처리한다.

| 레벨 | 직급명(안) | 해금 요소 | 직책 |
|---|---|---|---|
| Lv.0 | 신입 인턴 | 잡무 7종 | - |
| Lv.1 | 견습 인턴 | 샴푸 | - |
| Lv.2 | 보조 인턴 | 파마 롤 말기 | - |
| Lv.3 | 숙련 인턴 | 염색 배합/도포 | - |
| Lv.4 | 베테랑 인턴 | 드라이(블로우) | 부인턴장 |
| Lv.5 | 수석 인턴 | 가발 커트 | 인턴장 |
| Lv.6 | 졸업반 인턴 | 모델 커트 | 졸업 평가 |

- **Lv.0 잡무 7종**: 수건 접기, 도구 정리, 음료 서비스, 바닥 청소, 세면대·거울 청소, 손님 응대 보조, 전화·예약 메모
- **승급 조건**: XP + 숙련도 조건 병행(예: 샴푸 A등급 10회). 승급 시 선배나 원장이 지켜보는 짧은 실기 평가 이벤트.
- **Lv.0은 2~3일 분량**으로 짧게 하고 초반 레벨업 속도를 빠르게 한다.

## 5. 시술과 시간 규칙

미니게임 플레이 시간과 게임 내 시계 흐름을 분리한다(시계 점프). 시술 시작 전 예상 소요시간을 표시해 플레이어가 감수하고 선택하게 한다.

| 시술 | 미니게임 | 게임 내 시계 | 비고 |
|---|---|---|---|
| 수건 접기 | 약 10초 | 1~2분 | 잡무 |
| 도구 정리 | 약 15초 | 2~3분 | 잡무 |
| 샴푸 | 약 20초 | 약 4분 | 회전율 핵심 |
| 파마 롤 말기 | 약 35초 | 약 25분 | 이후 방치 시간 |
| 염색 배합/도포 | 약 35초 | 약 25분 | 이후 방치 시간 |
| 드라이 | 약 30초 | 약 12분 | 만족도 영향 최대 |

- **방치 시간**: 파마·염색 후 15~20분은 인턴이 자유롭다. 헹굼 타이밍이 늦거나 빠르면 만족도가 감소한다.
- **디자이너 속도 배율**: 같은 시술도 디자이너마다 시계 흐름이 다르다.
- 음료 서비스와 바닥 청소는 미니게임, 나머지 잡무는 선택형 행동으로 시작한다.

## 6. 인원 구성

| 구분 | 인원 | 비고 |
|---|---|---|
| 디자이너 | 10~12명 | 서사를 깊게 쓸 핵심은 3~4명 |
| 원장 | 1명 | 승급 심사, 본사 점검 대응 |
| 인턴 | 5~6명 (플레이어 포함) | 디자이너 : 인턴 = 2 : 1 이상 유지(인력난 설정) |

인턴 구성 예시: 인턴장 NPC(Lv.5), 부인턴장 NPC(Lv.4), 중간 인턴 NPC 1~2명(Lv.2~3), 동기 NPC 1명(Lv.0), 플레이어(Lv.0, 막내).

## 7. 직책과 승계 서사

직책은 인턴장·부인턴장 한 명씩이다. 직책자는 인턴 휴식 배정과 업무 분배 권한을 갖는다.

| 권한 | 부인턴장 (Lv.4) | 인턴장 (Lv.5) |
|---|---|---|
| 휴식 배정 | 일부 (인턴장 승인 필요) | 최종 결정 |
| 업무 분배 | 요청 일부를 인턴에게 넘김 | 전체 요청 배분 |
| 책임 | 분배 실수 시 작은 감점 | 호감도·매장 평가에 큰 영향 |

**서사 흐름**
1. 초반(Lv.0~3): 선배 인턴의 배정을 받으며 일을 배운다.
2. 1차 전환점(Lv.4): 인턴장 졸업, 플레이어가 부인턴장을 승계한다.
3. 2차 전환점(Lv.5): 인턴장도 졸업, 플레이어가 인턴장이 된다.
4. 후반(Lv.5~6): 새 막내가 입사하고, 플레이어가 가르치며 졸업 평가를 준비한다.

선배 졸업 시점은 플레이어 레벨에 연동하거나 이벤트로 고정하고 레벨업 속도를 맞춘다.

## 8. 요청 시스템 (확률 기반)

1. 레벨별 잡무/시술 비중으로 먼저 결정한다.
2. 디자이너별 확률표로 세부 항목을 뽑는다.
3. 미해금 시술이 뽑히면 잠금 요청이 되며, 일부만 화면에 노출한다.

| 레벨 | 잡무 | 시술 | 잠금 요청 노출 |
|---|---|---|---|
| Lv.0 | 45% | 55% | 15% |
| Lv.1 | 40% | 60% | 15% |
| Lv.2 | 33% | 67% | 12% |
| Lv.3 | 27% | 73% | 10% |
| Lv.4 | 22% | 78% | 0% |
| Lv.5~6 | 20% | 80% | 0% |

- Lv.4부터 잡무는 직접 수행보다 후배에게 분배하는 업무가 된다.
- **보정 장치**: 호감도, 예약표 연동, 시간대(오전 잡무 / 점심 후 샴푸 / 저녁 드라이), 디자이너의 바쁨.
- **잠금 요청 연출**: 응원 톤의 선배 대사, 견학 선택지(소량 XP·호감도, 기회비용 발생).

## 10. 난이도 규칙

| 항목 | 결정 요인 |
|---|---|
| 동시 요청 수 | 레벨 (Lv.0 1~2건 → Lv.4 5건, Lv.5~6 추가 조정) |
| 요청 제한시간 | 디자이너 참을성 + 레벨 보정 (Lv.0 약 40초 → Lv.4 약 20초) |
| 시술 소요시간 | 시술 종류 + 디자이너 속도 배율 |

- 제한시간을 넘긴 요청은 디자이너가 직접 처리하며 호감도와 매장 효율이 떨어진다.
- 요청이 한가했다가 몰리는 파동을 주어 틈 휴식과 연결한다.
- 난이도가 오를수록 편의 요소(선반 확장, 단골 선배의 도움)를 함께 해금한다.

## 11. 커트와 졸업

- **Lv.5 가발 커트**: 실패 부담이 없는 연습용. 야간 연습과 승급 과제가 주 무대이며 원랭스, 단발, 레이어드 순으로 기법을 해금한다.
- **Lv.6 모델 커트**: 되돌릴 수 없는 정밀 조작. 원장과 수석 디자이너가 지켜보는 졸업 평가이며, 통과하면 디자이너 과정이 해금된다.

## 12. 랜덤 인턴 생성 시스템

새 게임 시작 시 인턴을 한 번 뽑고, 그 판 동안 고정한다. 인턴 1명당 성격 1 + 업무 스타일 1 + 버릇 1을 뽑으며 각 항목은 시스템 수치에 영향을 준다.

**성격 (10종)**: 열정 과다(빠르지만 실수 많음), 느긋함(안정적·느림), 눈치 빠름(호감도 상승 빠름), 소심함(지적에 위축·칭찬에 크게 상승), 허세(어려운 일 자원·성공률 변동 큼), 깐깐함(품질 높음·느림), 긍정왕(실패해도 컨디션 하락 적음), 수다쟁이(만족도 보너스·시간 지연), 승부욕(라이벌과 비교 시 성능 상승), 무뚝뚝(응대 점수 낮음·품질 안정)

**업무 스타일 (10종)**: 샴푸 달인, 염색 달인, 손이 빠름(시계 ×0.85·품질 약간 감소), 꼼꼼함(시계 ×1.15·품질 보너스), 잡무 장인, 만능형, 드라이 감각, 롤 장인, 응대 천재, 멀티태스커(방치 시간 활용 효율 상승)

**버릇/약점 (10종)**: 땡땡이, 먹는 데 진심, 쉽게 지침, 지각, 선배 눈치 과다, 전화 공포증, 손 떨림(긴장 구간 품질 하락), 방향감각 부족(도구 위치 혼동), 졸음(오후 속도 하락), 연애 고민(랜덤 이벤트로 집중 못 하는 날)

**밸런스**: 각 항목에 -2~+2 점수를 매기고 한 인턴의 합이 +1~+2가 되도록 뽑는다. 범위를 벗어나면 다시 뽑는다.

**제외 조합**: 손이 빠름+느긋함, 꼼꼼함+열정 과다, 잡무 장인+지각, 깐깐함+졸음, 소심함+허세, 응대 천재+무뚝뚝, 손 떨림+승부욕

**역할별 적용**

| 인턴 | 랜덤 범위 |
|---|---|
| 인턴장 NPC | 엄격한 선배 톤 고정, 성격은 깐깐함·눈치 빠름·느긋함 중에서 뽑기 |
| 부인턴장 NPC | 다정한 선배 톤 고정, 허세·소심함 제외 |
| 중간 인턴, 동기, 새 막내 | 3개 축 모두 완전 랜덤 |

**대사 템플릿**: 성격 10종 기준으로 제작(첫 소개, 휴식·업무 배정 반응, 졸업 이벤트, 새 막내 입사). 1차로 열정 과다·소심함·느긋함·허세 4종을 만들고 나머지는 2차에 추가하며, 대사가 없는 성격은 기본 대사를 쓴다.

**이름·별명**: 성 12종 + 이름 40종 풀에서 조합하고, 성격에 맞는 별명 풀을 따로 둔다(예: 수다쟁이 → 스피커).

외형은 처음에는 고정 몇 벌 중 선택하고 파츠 랜덤은 후속으로 미룬다.

## 13. 플랫폼과 모바일 설계 원칙

- **플랫폼**: 모바일 (Android/iOS), **가로 화면 고정**
- **엔진**: Unity (C#), 1인 개발

**모바일 설계 원칙**
1. **요청 UI 단순화**: 요청 카드는 아이콘 중심의 한 줄 구성(디자이너 얼굴, 시술 아이콘, 남은 제한시간 바)으로 하고, 동시 요청이 5건 이상이어도 한 화면에 들어가게 한다. 예약표는 버튼을 눌러 여는 방식으로 두고, 영업 중에는 다음 예약 1~2건만 상단에 요약한다.
2. **중단과 이어하기**: 전화, 알림, 앱 전환 시 영업 중 자동 일시정지. 하루 시작·마감 시점과 파트 전환마다 자동 저장하며, 영업 도중 종료하면 복귀 시 일시정지 상태로 이어서 한다.
3. **터치 정확도**: 드래그형 미니게임은 판정을 너그럽게 잡는다. 염색 도포와 모델 커트 같은 정밀 조작은 확대 보조와 가이드 선을 제공한다. 손가락에 가려지지 않게 조작 영역과 결과 표시 영역을 분리한다.
4. **세션 길이**: 하루 한 판은 현실 약 10~15분 이내(선택형 파트 포함)를 목표로 한다.

## 14. 수익 모델 (무료 + 광고 + 인앱결제)

기본은 무료 게임이며 광고와 인앱결제로 수익을 낸다. 아래는 초안 원칙이며 출시 전에 다시 검토한다.

**원칙**
- 레벨업, 시술 해금, 졸업 평가 통과는 **결제로 건너뛸 수 없다.** 성장 서사가 이 게임의 핵심이기 때문이다.
- 영업 중 강제 광고는 넣지 않는다. 광고는 **플레이어가 선택하는 보상형 광고**를 중심으로 한다.

**보상형 광고 후보**
- 컨디션(피로도) 회복, 아침 버프 추가, 정산 시 팁·XP 보너스 2배, 야간 연습 추가 기회, 실패한 하루 한 번 재도전

**광고 위치**: 하루 종료 후 정산 화면, 파트 전환 구간처럼 흐름이 끊겨도 되는 곳에만 둔다.

**인앱결제 후보**
- 광고 제거 패키지
- 외형 아이템: 인턴 유니폼, 헤어 스타일, 미용실 인테리어 (성능에 영향 없음)
- 편의 아이템: 정리 선반 추가 등 (난이도를 낮추는 정도가 지나치지 않게 조정)
- 후속 콘텐츠: 디자이너 편 해금 방식은 별도 결정 필요(결제로 해금하면 인턴 편 엔딩 보상과 충돌)

**주의점**
- 광고 시청이 필수가 되는 구조(피로도가 너무 빨리 쌓임 등)는 피한다.
- 시간 제한 요청이 핵심인 게임이라 유료 시간 정지·연장 아이템은 밸런스를 크게 깨므로 제외하거나 엄격히 제한한다.

## 16. 프로토타입에서 확정한 플레이 규칙 (v2.2)

프로토타입을 만들며 정한 규칙입니다. 앞 장과 다르면 이 장이 우선합니다. 숫자는 모두 임시값입니다.

### 16-1. 화면과 조작
- 카드 방식을 버리고 **위에서 내려다본 미용실 평면**으로 변경. 모든 인물은 도형 캐릭터(그림은 나중에 교체)
- 플레이어는 인턴 한 명("나")을 탭으로 이동. 다른 인턴(NPC)은 후속 작업
- 디자이너 자리 12개(위 6, 아래 6), 가운데 복도, 왼쪽에 휴게실·재료실, 오른쪽에 샴푸실·시술석·커트석
- 디자이너가 요청하면 그 머리 위에 말풍선(요청 내용 + 남은 시간 막대). 예약 손님은 연한 파란색, VIP는 노란색, 아직 못 하는 시술은 회색(견학 XP +1)
- 말풍선을 누르면 디자이너 자리로 가서 손님을 모시고 단계별 구역으로 이동

### 16-2. 하루 시간
- 영업 시간 10:00~18:00을 현실 4분(240초)으로 진행. 게임 시계는 현실 1초에 2분
- 요청 제한시간, 이동 속도, 미니게임 시간은 현실 초 기준
- 아침 예약표(가로 시간, 세로 디자이너, 칸에 시술 이름)가 영업 중 해당 시간에 실제 요청이 됨. 예약 완료 +10점, VIP +30점

### 16-3. 시술 진행 순서
| 시술 | 순서 |
|---|---|
| 샴푸 | 샴푸 |
| 드라이 | 샴푸 → 드라이 |
| 커트 | 샴푸 → 커트 → 드라이 |
| 파마 | 샴푸 → 커트 → 펌 → 샴푸 → 드라이 |
| 염색 | 염색 → 샴푸 → 드라이 |
| 탈색 | 탈색 → 샴푸 → 염색 → 샴푸 → 드라이 |

- 구역: 샴푸는 샴푸실, 펌·염색·탈색은 시술석, 커트는 커트석, 드라이는 디자이너 자리
- 단계마다 인턴이 직접 할 수 있는 레벨이 있음: 샴푸 1, 펌 2, 염색·탈색 3, 드라이 4, 커트 5. 직접 할 수 있으면 약 1.5초, 못 하면 디자이너가 하는 동안 약 4초 기다림
- 시술 자체가 아직 못 하는 것이면 잠금 요청(견학만 가능). 탈색은 임시로 Lv.3 해금, 커트(가발 Lv.5, 모델 Lv.6)와 탈색은 모든 디자이너 공통 확률(약 20%, 약 12%)
- 점수는 10 + 5 × 단계 수. 요청 제한시간은 단계가 하나 늘 때마다 50%씩 길어짐

### 16-4. 바닥 청소
- 잡일(수건 접기 등)은 더 이상 카드로 나오지 않음
- 바닥 청소는 **커트 단계가 끝난 뒤** 커트석에 나타나는 요청(제한 45초, 머리카락 쓸기 미니게임)

### 16-5. 재료실
- 재료: 수건 30, 도구 20, 음료 20, 청소용품 5. 매일 가득 채워서 시작
- 시간이 지나면 조금씩 줄고, 시술 단계마다 쓰임(샴푸=수건, 펌=도구+음료, 염색·탈색·커트=도구, 드라이=수건+청소용품)
- 재료가 0이거나 필요한데 없으면 선배에게 혼남(점수 -10, 같은 재료는 20초에 한 번)
- 재료실에서 하나를 고르면 한 번에 전부 채움(게임 시계 4분). 도중에 나가면 찬 만큼만 남음. 다 채울 때마다 XP +1
- 응대 보조, 전화·예약 메모 같은 잡일은 재고로 만들기 어려워 보류

### 16-6. 피로도와 휴식
- 시술 단계를 마치면 피로도가 쌓이고, 높을수록 새 요청의 제한시간이 최대 30% 줄어듦
- 하루 휴게시간은 총 60분(게임 시계). 일찍 나오면 남은 시간만큼 다시 쉴 수 있음
- 휴게실에서 활동을 고름(고르는 동안 시계 정지): 밥 먹기 30분 -30(12~14시 -45), 낮잠 40분 -50(잔소리 기준 1 낮아짐), 핸드폰 15분 -10, 스트레칭 10분 -10
- 쉬는 중 손님이 밀리면(동시 요청 최대치 - 1, 최소 2장) 잔소리를 듣고 점수 -20, 휴식 종료
- 손님을 데리고 가던 중 휴게실·재료실로 가면 손님은 자리로 돌아가고 그 요청은 처음부터 다시

## 15. 미결정 사항 (갱신)

1. 고정 인물: 원장 + 핵심 디자이너 4명의 초안 완료(characters/ 폴더 참고, 이름은 가명). 나머지 디자이너 7명과 선배 인턴의 성격은 랜덤 시스템으로 처리
2. Lv.5~6 영업 난이도 수치
3. 개발 일정과 단계별 목표 (엔진은 Unity로 확정, 1인 개발)
4. 직책자일 때 NPC 인턴의 행동 방식 (기본 AI 자동 + 플레이어 개입 권장)
5. 디자이너 편(후속 과정) 설계와 해금 방식
6. 잡무 비중과 잠금 요청 노출 비율의 실제 테스트 조정
7. 인앱결제 상품 구성과 광고 SDK
8. 디자이너별 커트·탈색 확률 (지금은 공통), 응대 보조·전화 메모 같은 잡일의 재료/업무화
9. 바닥 청소 미니게임 보상과 청소용품 연동, 모바일 한글 폰트 포함
